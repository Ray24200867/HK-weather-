# 香港有幾熱｜完整網頁

這個資料夾包含文章首頁、樣式、資料、圖片、五個互動圖表及本機預覽程式。請保留整個資料夾的目錄結構；傳送給別人時，直接傳送同名 ZIP 壓縮檔即可。

## 預覽

電腦安裝 Node.js 後，在本資料夾執行 `node server.mjs`，再用瀏覽器開啟 `http://127.0.0.1:8783/`。

即時香港暑熱指數需要網絡連線。直接雙擊 `index.html` 以 `file://` 開啟時，部分資料和互動可能無法載入。

## 內容

- `index.html`：完整文章網頁。
- `design-v1/`、`data/`：主頁樣式、程式及資料。
- 中文命名的資料夾：圖表、圖片及互動組件。
- `server.mjs`：本機預覽伺服器。

原稿中的「待採訪替換」等編輯標記保持原樣。
